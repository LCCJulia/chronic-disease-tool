慢性病診斷與用藥分類工具

貼上診斷與藥物清單，即時判斷指定疾病／生活習慣與藥物分類。

本工具完全在瀏覽器本機執行，不需登入、不上傳資料、不使用 Cookie / localStorage，也不保存任何輸入內容。 僅供資料整理與研究輔助，不取代臨床診斷或處方判斷。
1

診斷／病史判斷

支援中文、英文與常用縮寫。DM、HT、HL、HU 採完整單字比對，避免誤判其他英文單字。 65歲以上可由「Age 72」、「72 years old」、「72歲」等格式判斷。
2

藥物分類判斷

支援學名、常見商品名與複方。Dapagliflozin 複方會同時標示「Dapagliflozin」與「Dapagliflozin及其複方」。
目前內建診斷關鍵字
糖尿病：DM / diabetes / diabetes mellitus / 糖尿病
高血壓：HT / hypertension / 高血壓
高血脂：HL / hyperlipidemia / hyperlipidaemia / 高血脂 / 高脂血症
心血管病史：heart disease / coronary heart disease / stroke / 心血管疾病 / 心血管病史
高尿酸：HU / hyperuricemia / 高尿酸 / 高尿酸血症
肥胖：obesity / obese / 肥胖
抽菸：tabacco / tobacco / smoking / smoker / 抽菸 / 吸菸
另外保留蛋白尿、家族腎臟病史、65歲以上長者與長期服用止痛之判斷。
若原始資料包含院內藥碼、中文藥名或特殊縮寫，可再於程式中的 keyword arrays 增加同義詞。
